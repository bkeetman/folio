# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer still needs to evaluate the request. |
| `needs-info` | `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is sufficiently specified for autonomous work. |
| `ready-for-human` | `ready-for-human` | The implementation or decision requires a person. |
| `wontfix` | `wontfix` | The request will not be actioned. |

Program-specific workflow labels may supplement these roles. In particular, `blocked` identifies an issue with open dependencies and `in-progress` identifies the currently active implementation slice.
